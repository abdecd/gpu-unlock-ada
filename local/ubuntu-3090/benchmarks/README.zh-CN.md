# cuBLAS 性能与抽样数值检查

这是已用于四卡 3090 原厂/解锁对照的测试程序。运行会产生 GPU 负载，先确认无人使用。
无需 root；不加载解锁模块、不修改启动配置。保留原始基线，改动源码请另建实验目录。

```bash
/usr/local/cuda-12.2/bin/nvcc -O3 -arch=sm_86 bench.cu -lcublas -o bench
python3 run.py stock     # 普通启动下运行
python3 run.py unlocked  # 已经通过专用入口启动后运行
python3 compare.py
```

换机器需调整 run.py 的 CUDA 路径。该脚本依次测试所有可见卡，发现计算进程则中止。
每模式测试 256/4096/8192 阶方阵；256 阶检查全部全 1 输出，大矩阵检查 32 个确定性
CPU 参考点（不是全量验证）。FP32 累加误差阈值 0.05；FP16 累加只检查有限值并记录误差。
性能为 10 次预热、5 组各 30 次，汇总中位数；每 500ms 采集遥测。

结果目录保存环境、二进制哈希、逐卡 CSV/错误日志、遥测和 summary.csv。
compare.py 自动选取最新有汇总的 stock/unlocked 目录，按 UUID/模式/尺寸匹配；
不会验证二进制哈希或环境一致，比较前必须人工核对。GEMM 结果不等于实际训练吞吐。

注意：运行生成的环境和遥测文件包含主机名、内核命令行、GPU UUID/序列号及进程等信息，
属于本地诊断数据；分享前必须脱敏，不应直接提交到公开仓库。
